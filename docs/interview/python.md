## 41. 【推导】Python 是编译型语言还是解释型语言？代码从源文件到执行会经历哪些步骤？ {#q-41}

**参考答案：**

通常 CPython 先将源代码编译为字节码，再由虚拟机解释执行，可能缓存为 .pyc。因此“编译型/解释型”不是语言的绝对二分；PyPy 等实现还可使用 JIT，具体执行方式取决于实现。

## 42. 【推导】Python 解释器是什么？CPython 是什么，与其他 Python 实现有什么区别？ {#q-42}

**参考答案：**

解释器负责解析、编译和执行 Python 代码；CPython 是主要由 C 实现的参考实现。PyPy 侧重 JIT，其他实现面向不同宿主与兼容目标；性能、扩展 ABI 和标准库支持应按实现核对。

## 43. 【推导】pip 是什么？如何安装和管理第三方包？ {#q-43}

**参考答案：**

pip 是 Python 包安装工具，常用 python -m pip install 包名、uninstall、list、show。优先在虚拟环境中操作，固定依赖版本并使用可信索引；安装包可能执行构建代码，包名与版本需要核对。

## 44. 【推导】什么是 Python 虚拟环境？为什么需要使用虚拟环境？ {#q-44}

**参考答案：**

虚拟环境隔离项目的解释器关联与 site-packages，避免不同项目依赖冲突。用 python -m venv .venv 创建后激活或直接调用其中的 python；它不是操作系统安全沙箱，也不隔离所有系统资源。

## 45. 【推导】Python 2 和 Python 3 有哪些主要区别？ {#q-45}

**参考答案：**

Python 3 将 str 统一为 Unicode，区分 bytes，print 成为函数，整数 / 默认真除法，range 返回惰性序列，并完善异常与迭代语义。Python 2 已停止官方维护，新项目应选受支持的 Python 3。

## 46. Python 常见的数据类型有哪些？ {#q-46}

**参考答案：**

基本类型有 int、float、complex、bool、str、bytes、NoneType；容器有 list、tuple、dict、set、frozenset。还包括函数、类、实例与迭代器；选择时关注可变性、有序性、哈希能力和操作复杂度。

## 47. 【推导】Python 是动态类型语言是什么意思？变量与类型之间是什么关系？ {#q-47}

**参考答案：**

对象携带类型，名字绑定对象，运行中同一个变量名可绑定不同类型对象。动态类型不等于弱类型，例如字符串与整数不能直接相加；类型注解通常由静态工具检查，不会自动强制运行时约束。

## 48. 【推导】int、float、str、bool 之间如何进行类型转换？有哪些需要注意的情况？ {#q-48}

**参考答案：**

用 int、float、str、bool 构造转换；int('12') 可行，int('1.2') 报错，int(1.9) 向零截断。bool('False') 仍为 True，因为字符串非空；处理用户输入时需校验格式、范围和浮点精度。

## 49. 【推导】Python 中 None 是什么？它与 0、False、空字符串有什么区别？ {#q-49}

**参考答案：**

None 是表示“没有值/未提供”的单例，常用 is None 判断。0、False、空字符串和 None 都是假值，但语义不同；用 if not x 会把它们混在一起，区分缺省值时应显式判断。

## 50. 【推导】Python 中可变类型和不可变类型有什么区别？分别有哪些常见类型？ {#q-50}

**参考答案：**

list、dict、set 可原地改变；int、str、tuple 等不可原地改变。不可变 tuple 内仍可引用可变对象，哈希性取决于全部元素；不可变性描述对象本身，不等于其引用的整个对象图都不可变。

## 51. Python 中 == 和 is 有什么区别？ {#q-51}

**参考答案：**

== 比较值，通常调用 __eq__；is 比较对象身份。判断 None 用 is；不要依赖小整数或字符串驻留，用 is 比较普通数值或文本会产生不可靠结果。

## 52. 【推导】Python 中 and、or、not 如何使用？短路求值如何工作？ {#q-52}

**参考答案：**

and、or 从左到右短路，返回参与求值的操作数而非强制 bool；not 返回布尔值。例 0 or 5 得到 5，[] and f() 不调用 f；默认值若允许 0，应判断 None 而不是简单使用 or。

## 53. if、elif、else 的执行流程是什么？ {#q-53}

**参考答案：**

按顺序判断 if 和各 elif，命中第一个真值分支后不再判断后续分支；都不成立执行 else。缩进决定代码块，互斥条件用同一链，多个独立 if 可能执行多块。

## 54. 【推导】for 和 while 有什么区别，分别适用于哪些场景？ {#q-54}

**参考答案：**

for 遍历可迭代对象，适合集合、文件和有限序列；while 按条件持续执行，适合未知迭代次数。避免修改正在遍历的容器，while 应设计推进条件和终止条件，防止死循环。

## 55. 【推导】break、continue、pass 分别有什么作用和区别？ {#q-55}

**参考答案：**

break 退出最近一层循环，continue 跳过本轮剩余代码，pass 什么也不做，常作占位。循环的 else 仅在未被 break 终止时执行，return 则退出整个函数。

## 56. 【推导】List 和 Tuple 有什么区别，分别适用于哪些场景？ {#q-56}

**参考答案：**

list 可变，适合增删改集合；tuple 不可变，适合固定记录和返回多个值。tuple 仅在元素都可哈希时能作字典键；两者均支持索引切片，不能只用“tuple 一定更快”决定选型。

## 57. 【推导】Set 有什么特点？为什么可以用来去重？ {#q-57}

**参考答案：**

set 保存不重复的可哈希元素，适合成员判断、去重、交并差集。哈希确定候选位置，再用相等判断消除重复；它不提供可靠的业务顺序，保序去重可在合适场景用 dict.fromkeys。

## 58. 【推导】Dict 是什么？为什么根据 Key 查询通常很快？ {#q-58}

**参考答案：**

dict 是键值映射，基于哈希表使查找平均为 O(1)，最坏情况可能退化。键必须可哈希，哈希冲突后还需相等比较；现代 Python 保持插入顺序，但不等于自动按键排序。

## 59. 【推导】Python 中列表切片是什么？正数索引、负数索引和步长如何使用？ {#q-59}

**参考答案：**

切片 s[start:stop:step] 左闭右开，负索引从末尾计数，负步长反向遍历，如 s[::-1]。越界切片通常截断，步长不能为 0；list 切片产生浅拷贝，不会深拷贝内部元素。

## 60. 【推导】Python 字符串为什么是不可变对象？修改字符串时实际发生了什么？ {#q-60}

**参考答案：**

str 对象创建后内容不能原地修改，有利于共享、哈希和语义稳定。拼接或 replace 返回新字符串，变量可以重新绑定；大量拼接通常先收集片段再 join，减少重复复制。

## 61. 【推导】Python 如何定义函数？return 和 print 有什么区别？ {#q-61}

**参考答案：**

def 定义函数，return 将值交给调用方并结束当前调用，省略时返回 None。print 只是输出副作用且通常返回 None；需要继续计算的数据应通过 return 返回，而不是从控制台文本获取。

## 62. 【推导】位置参数、默认参数、关键字参数有什么区别？如何定义和调用？ {#q-62}

**参考答案：**

位置参数按顺序绑定，关键字参数按名字绑定，默认参数在缺省时使用且在定义时求值。定义可用 / 指定仅位置、* 指定仅关键字；调用中不能让同一参数重复接收值。

## 63. *args 和 **kwargs 分别有什么作用？ {#q-63}

**参考答案：**

*args 收集多余位置参数为 tuple，**kwargs 收集多余关键字参数为 dict。名称可改，星号语法才是关键；适合包装函数，但公共接口应尽量提供清晰签名与校验。

## 64. 【推导】*args 与 **kwargs 如何参与参数传递和解包？使用时有哪些顺序要求？ {#q-64}

**参考答案：**

定义顺序通常为位置参数、默认参数、*args、仅关键字参数、**kwargs；调用时 *iterable 展开位置值，**mapping 展开字符串键参数。注意重复绑定和缺失必填参数；转发时可用 f(*args, **kwargs)。

## 65. 【推导】Python 中局部变量、全局变量以及 global、nonlocal 的作用和区别是什么？ {#q-65}

**参考答案：**

名称通常按 LEGB：局部、外层函数、全局、内建查找。global 声明绑定模块全局名字，nonlocal 绑定最近外层函数已有名字；修改对象内容和重新绑定名字不同，尽量通过参数与返回值减少隐式共享状态。

## 66. 【推导】Lambda 表达式是什么？和普通函数有什么区别？ {#q-66}

**参考答案：**

lambda 创建只包含一个表达式的匿名函数，表达式结果即返回值，也遵守闭包和作用域规则。适合排序 key 等短逻辑；复杂分支、文档和多条语句应使用 def，不应牺牲可读性。

## 67. 【推导】Python 中类和对象是什么？如何定义类并创建对象？ {#q-67}

**参考答案：**

类定义对象的数据和行为，实例是按类创建的具体对象。用 class User: 定义，再 User() 构造，通过 self 设置实例属性；类属性由实例共享，实例独立可变数据一般放 __init__ 中。

## 68. 【推导】Python 中 __init__ 和 self 分别有什么作用？ {#q-68}

**参考答案：**

__init__ 在实例创建后初始化，必须返回 None；真正负责创建的是 __new__。self 是实例方法接收当前对象的惯用参数名，调用 obj.method() 时自动传入，不是特殊关键字。

## 69. 【推导】Python 中什么是继承？子类如何继承父类并重写方法？ {#q-69}

**参考答案：**

用 class Child(Parent) 声明继承，在子类定义同名方法覆盖父类行为。通过 super() 依 MRO 调用协作式父类实现，多继承尤其需保持一致签名；优先用继承表达“是一个”的关系。

## 70. Python 中什么是方法重写和多态？ {#q-70}

**参考答案：**

重写是子类提供同名方法实现；多态是调用方使用共同接口，具体行为由对象决定。Python 的鸭子类型允许无共同父类也能多态；应保持方法契约，避免子类改变调用者预期。

## 71. 【推导】实例方法、类方法和静态方法有什么区别？分别适用于哪些场景？ {#q-71}

**参考答案：**

实例方法接收 self、访问实例状态；@classmethod 接收 cls，适合替代构造器和类级行为；@staticmethod 不自动接收实例或类，适合与类有关的纯工具逻辑。可共享状态时需明确作用域。

## 72. 【推导】Python 中 try、except、else、finally 分别有什么作用，执行顺序是什么？ {#q-72}

**参考答案：**

try 执行主体，异常匹配 except；无异常时执行 else；finally 在退出该结构时清理，即使有 return/异常也通常执行。先捕获具体异常，避免在 finally 中 return 覆盖原结果或异常。

## 73. 【推导】Python 如何读取和写入文件？with 语句在文件操作中有什么作用？ {#q-73}

**参考答案：**

with open(path, 'r', encoding='utf-8') as f 可读取，'w' 覆盖写入，'a' 追加，二进制用 b 模式。with 自动关闭文件，即使出现异常也会清理；大文件逐行/分块，重要写入可考虑临时文件加原子替换。

## 74. 【推导】Python 中模块和包有什么区别？import 如何导入模块或包？ {#q-74}

**参考答案：**

模块通常是可导入的 .py 文件；包组织多个模块，普通包有 __init__.py，命名空间包可无该文件。import mod 绑定模块，from mod import name 绑定成员；避免文件名遮蔽标准库和循环导入。

## 75. 【推导】venv、pip、requirements.txt 分别有什么作用，如何配合管理项目环境与依赖？ {#q-75}

**参考答案：**

venv 隔离依赖环境，pip 安装依赖，requirements.txt 记录安装需求。创建环境后用其 python -m pip install -r requirements.txt；为可复现性固定直接及传递版本，必要时带哈希，并统一解释器和平台。

## 76. 【推导】Iterable、Iterator 和 Generator 有什么区别与联系？ {#q-76}

**参考答案：**

Iterable 能返回迭代器，Iterator 实现 __iter__/__next__ 并保存遍历进度。Generator 是由含 yield 的函数等创建的特殊迭代器，惰性产值；生成器通常只能消耗一次。

## 77. 【推导】什么是装饰器？为什么不用修改原函数就能扩展其功能？ {#q-77}

**参考答案：**

装饰器接收函数并返回包装后的可调用对象，@deco 等价于 f = deco(f)。包装器在调用前后增加日志、校验等行为，闭包保存原函数；用 functools.wraps 保留元数据，异步函数需异步包装。

## 78. 【推导】Python 中赋值、浅拷贝和深拷贝有什么区别？ {#q-78}

**参考答案：**

赋值只增加同一对象的引用；copy.copy 复制外层，嵌套对象仍共享；copy.deepcopy 递归复制对象图并处理循环引用。锁、文件、连接等资源不能当作普通数据随意复制，需自定义复制策略。

## 79. 【推导】为什么不建议把 List、Dict 等可变对象作为函数的默认参数？ {#q-79}

**参考答案：**

默认参数在函数定义时求值一次，可变对象会被多次调用共享。改为 def f(items=None):，函数内部在 items is None 时创建新 list；不要用 if not items，以免把合法空容器也当作未提供。

## 80. 【推导】同步、异步、阻塞、非阻塞分别是什么意思？它们之间有什么区别与联系？ {#q-80}

**参考答案：**

同步描述任务的完成/调用协作方式，异步允许完成后通知；阻塞描述等待期间线程不能继续，非阻塞表示调用立即返回结果或未就绪状态。这两组不是同义词，异步函数内部仍可能执行阻塞 I/O。

## 81. 【推导】async、await 和 asyncio 分别是什么？如何配合编写异步程序？ {#q-81}

**参考答案：**

async def 定义协程函数，调用得到协程对象；await 等待可等待对象，asyncio 负责事件循环、任务和异步 I/O。入口用 asyncio.run(main())，并发用任务或 gather；阻塞操作可用 to_thread 等隔离。

## 82. 【推导】list、tuple、dict、set 各自适合哪些场景？选择时需要考虑哪些因素？ {#q-82}

**参考答案：**

list 用于可变有序序列，tuple 用于固定记录，dict 用于键值查询，set 用于去重和集合运算。综合是否需保序、重复、索引和哈希查找选择；大型数据还需测内存与具体操作复杂度。

## 83. 【推导】浅拷贝与深拷贝有什么区别？哪些场景需要深拷贝？ {#q-83}

**参考答案：**

浅拷贝只复制外壳，深拷贝递归复制嵌套对象。需要独立修改嵌套配置时可 deepcopy；对只读结构或大型对象可共享/结构化更新，不必一律深拷贝，资源对象需要明确生命周期。

## 84. Python 装饰器是如何工作的？ {#q-84}

**参考答案：**

@outer 位于 @inner 上方时，相当于 f = outer(inner(f))，定义阶段完成装饰，调用阶段运行包装逻辑。带参数装饰器再加一层工厂；wraps 保留函数名和文档，注意闭包捕获与异步兼容。

## 85. 【推导】with 语句与上下文管理器的执行流程是什么？__enter__ 和 __exit__ 分别何时调用？ {#q-85}

**参考答案：**

with 先求值上下文管理器并调用 __enter__，其返回值绑定 as 变量，离开主体调用 __exit__(exc_type, exc, tb)。__exit__ 返回真值可吞掉异常；若 __enter__ 本身失败不会调用该管理器的 __exit__，复杂场景可用 ExitStack。

## 86. 【推导】迭代器与生成器有什么区别？yield 如何工作？ {#q-86}

**参考答案：**

迭代器通过 __next__ 返回值并以 StopIteration 结束；生成器由 yield 自动保存局部状态与执行位置，每次 next 从暂停处继续。它节省一次性物化内存，也支持 send/throw/close；耗尽后不会自动重置。

## 87. 【推导】asyncio 事件循环与 async/await 如何协作，实现协程调度？ {#q-87}

**参考答案：**

事件循环维护就绪任务和 I/O 等待，协程在 await 未完成对象时让出控制，完成后被重新调度。协作式调度意味着长同步循环会阻塞其他任务；设置超时、取消传播并正确清理资源。

## 88. 【推导】venv 与 pip 如何实现项目级依赖隔离和管理？ {#q-88}

**参考答案：**

venv 创建独立 site-packages，使用该环境的 python -m pip 安装即可作用于该项目。激活只是改变命令查找路径，也可直接调用 .venv 下解释器；提交依赖说明而非整个虚拟环境。

## 89. 【推导】typing 类型注解解决什么问题？如何使用常见类型注解辅助开发与静态检查？ {#q-89}

**参考答案：**

类型注解帮助 IDE 和 mypy/pyright 提早发现接口错误，例如 list[str]、dict[str, int]、T | None、Protocol、TypeVar。语法依 Python 版本而异；注解不默认执行运行时校验，外部输入仍需显式验证。

## 90. 【推导】Python 异常机制中，try/except/else/finally 分别如何执行？如何合理捕获和传播异常？ {#q-90}

**参考答案：**

try 主体异常由匹配的 except 处理，无异常才走 else，finally 做清理。只捕获能恢复的具体异常，用 raise 原样传播或 raise NewError(...) from exc 保留因果；不要用裸 except 隐藏取消和退出信号。

## 91. 【推导】列表推导式、字典推导式与集合推导式如何使用？与普通循环相比有什么特点？ {#q-91}

**参考答案：**

如 [x*x for x in xs if x > 0]、{x: f(x) for x in xs}、{f(x) for x in xs} 分别构建列表、字典、集合。表达式简洁但仍会物化结果；复杂逻辑改用循环，惰性处理用生成器表达式。

## 92. 【推导】多进程与多线程在 Python 中如何选择？GIL 对它们有什么影响？ {#q-92}

**参考答案：**

传统启用 GIL 的 CPython 中，多线程适合 I/O，纯 Python CPU 密集计算常选多进程；进程有序列化和内存成本。释放 GIL 的原生扩展及可选 free-threaded 构建改变该前提，不能断言所有 Python 线程都无法并行。

## 93. 常见魔术方法各自承担什么职责？ {#q-93}

**参考答案：**

__new__/__init__ 创建与初始化，__repr__/__str__ 表示对象，__len__/__iter__/__next__ 支持容器，__eq__/__hash__ 定义比较与哈希，__enter__/__exit__ 支持 with。实现时应遵守协议，例如相等对象必须有相同哈希。

## 94. import 语句背后的模块是如何加载的？ {#q-94}

**参考答案：**

import 首先查看 sys.modules 缓存，否则通过 finder 定位模块、loader 创建并执行模块，然后缓存对象。搜索受 sys.meta_path、sys.path 和包路径影响；循环导入可能遇到部分初始化模块，重复 import 通常不会重复执行模块体。

## 95. 【推导】dataclass 相比普通 class 解决了什么问题？有哪些常用功能与使用场景？ {#q-95}

**参考答案：**

@dataclass 自动生成 __init__、__repr__、__eq__ 等，适合配置和数据记录。可使用 frozen、slots、order、__post_init__；可变字段用 field(default_factory=list)，frozen 也不保证嵌套对象深度不可变。

## 96. 【推导】pathlib 相比 os.path 字符串路径操作有什么优势？如何完成常见路径与文件操作？ {#q-96}

**参考答案：**

pathlib.Path 用对象组合路径，如 Path(root) / 'data.txt'，提供 read_text、write_text、mkdir、glob 等接口，减少手动分隔符处理。仍需处理编码、权限、符号链接和平台差异，路径规范化不能替代访问控制。

## 97. 【推导】pytest 基础：如何组织测试与使用 fixture？ {#q-97}

**参考答案：**

pytest 通常以 test_*.py、test_* 函数组织测试，使用 assert 验证行为。fixture 通过函数参数注入依赖，支持 scope、yield 清理和参数化；用 tmp_path 隔离文件操作，测试不要依赖执行顺序。

## 98. 【推导】match-case 结构模式匹配能做什么？与 if/elif 有什么区别？ {#q-98}

**参考答案：**

match-case 对值做结构模式匹配，可解构序列、映射、类并带 guard，适合解析结构化消息。if/elif 更通用；case 中裸名字通常是捕获而非比较常量，_ 是通配，需留意匹配顺序。

## 99. 【推导】可变默认参数陷阱为何会发生？如何正确设置默认值以避免多次调用共享状态？ {#q-99}

**参考答案：**

def add(x, cache=[]) 的列表在定义时创建，后续调用都会引用它。使用 None 或独立哨兵作为默认值，在函数内部创建新容器；确需共享缓存时应明确生命周期、并发策略和清理边界。
