# 持续集成与部署

## 846. 什么是 CI/CD？ {#q-846}

**参考答案：**

CI 持续集成变更并自动构建/测试，Continuous Delivery 保持随时可发布，Continuous Deployment 将通过检查的变更自动上线。二者 CD 含义需明确，核心是小批量、可追溯、可验证与可回滚。

## 847. 从 Git Push 到上线经历哪些流程？ {#q-847}

**参考答案：**

Git push 触发流水线，安装固定依赖、静态检查/测试、构建扫描签名产物，部署测试/预发布，再审批或自动灰度至生产并观测。版本与配置绑定，数据库迁移保持兼容，异常可回滚。

## 848. 【推导】Jenkins、GitHub Actions、GitLab CI 有什么区别？如何选择？ {#q-848}

**参考答案：**

Jenkins 可高度自托管定制但运维成本较高，GitHub Actions 与 GitHub 事件/生态结合，GitLab CI 与 GitLab 平台和 runner 集成。按代码托管、网络隔离、凭据、执行成本与团队运维选择，价格/特性需按当时版本核实。

## 849. Pipeline 是什么，通常有哪些阶段？ {#q-849}

**参考答案：**

Pipeline 是自动化阶段和依赖的定义，常含 checkout、依赖安装、lint/typecheck、测试、构建、扫描、发布与验证。可并行独立步骤，缓存要正确绑定版本，失败不应继续发布不合格产物。

## 850. 滚动、蓝绿、灰度发布有什么区别？ {#q-850}

**参考答案：**

滚动逐批替换、资源额外需求较小但新旧并存；蓝绿准备完整新环境后切流，回退快但成本高；灰度/金丝雀只给少量流量验证。三者都需状态与数据库兼容，切流不自动回滚已写数据。

## 851. 【推导】Docker 是什么，为什么需要 Docker？ {#q-851}

**参考答案：**

Docker 通过镜像打包应用和依赖，用容器运行，改善环境一致性与分发。它利用操作系统隔离和资源控制，不包含独立内核；镜像固定不代表外部服务、架构和配置也相同。

## 852. Docker 和虚拟机有什么区别？ {#q-852}

**参考答案：**

容器共享宿主内核、启动快且资源开销低；虚拟机通过虚拟化运行独立来宾系统，隔离边界通常更强但更重。选择看多租户安全、内核需求与密度，不应把普通容器直接等同绝对安全沙箱。

## 853. Image 和 Container 有什么区别？ {#q-853}

**参考答案：**

Image 是分层、只读的应用模板，Container 是基于镜像创建的运行实例，带可写层、进程与网络配置。容器删除可丢失可写层，持久数据需 volume/外部存储；同镜像可启动多个实例。

## 854. Dockerfile 常用指令有哪些？ {#q-854}

**参考答案：**

FROM 选基础镜像，WORKDIR 设置目录，COPY 拷贝文件，RUN 构建执行，ENV 配置环境，USER 降权，EXPOSE 声明端口，CMD/ENTRYPOINT 定义启动。多阶段构建减产物，固定版本，不把密钥写进层或构建参数。

## 855. 【推导】Docker 端口映射和 Volume 有什么作用？如何使用？ {#q-855}

**参考答案：**

-p hostPort:containerPort 将宿主端口映射到容器端口，必要时限定监听地址；EXPOSE 不自动开放。Volume 持久化/共享数据，bind mount 映射指定宿主路径；挂载需最小权限，避免把宿主根目录交给不可信容器。

## 856. K8s 是什么，为什么需要 K8s？ {#q-856}

**参考答案：**

Kubernetes 编排容器，管理调度、期望副本、自愈、服务发现、配置和滚动更新。适合多服务与弹性运维，但有显著复杂度；小规模项目可先用托管平台/简单容器部署。

## 857. 【推导】Pod、Deployment、Service 有什么区别与联系？ {#q-857}

**参考答案：**

Pod 是最小调度单位，可含共享网络/卷的容器；Deployment 管无状态 Pod 的副本与版本更新；Service 提供稳定访问和选择器转发。Pod 可重建且 IP 会变化，有状态服务通常另用 StatefulSet 等控制器。

## 858. ConfigMap 和 Secret 有什么区别？ {#q-858}

**参考答案：**

ConfigMap 放非机密配置，Secret 放敏感数据，但 base64 编码不是加密。需配置静态加密、RBAC、最小挂载和轮换，避免日志暴露；环境变量方式的更新通常需重启进程。[官方文档](https://kubernetes.io/docs/concepts/configuration/secret/)

## 859. K8s 如何实现扩缩容和滚动更新？ {#q-859}

**参考答案：**

Deployment 改 replicas 或 HPA 根据指标调整副本，节点容量不足需节点扩容配合；滚动更新由 maxSurge/maxUnavailable 控制替换。readiness、资源请求和终止宽限影响可用性，长任务需先排空再停机。

## 860. Pod 启动失败应该如何排查？ {#q-860}

**参考答案：**

先 kubectl get/describe 看状态与 Events，再查 logs/--previous、镜像拉取、配置/密钥、资源和探针。Pending 多查调度/PVC，CrashLoopBackOff 查退出码/启动错误，OOMKilled 查内存；不要只反复删除 Pod。
