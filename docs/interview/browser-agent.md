# 浏览器 Agent

共 **14 题**，题号 **522–535**。 [返回分类总览](./)

> 答案用于面试复习与工程讨论，具体实现请结合项目锁定的版本验证。

## 522. 浏览器 Agent 解决什么问题？和传统浏览器自动化有什么区别？ {#q-522}

**参考答案：**

浏览器 Agent 根据语义目标感知页面、规划动作并观察结果，传统自动化多依赖预写脚本和确定路径。它适应性更强但成本和不确定性更高，关键稳定流程仍可用脚本，业务副作用需独立授权。

## 523. DOM 解析和截图视觉两条感知路径有什么区别？如何选择与融合？ {#q-523}

**参考答案：**

DOM 感知有语义和可访问性定位，适合结构化交互；截图视觉覆盖 canvas/布局但坐标和理解易受缩放影响。优先稳定语义定位，视觉补充，动作后用状态/页面证据验证，不能用旧截图盲点。

## 524. 浏览器 Agent 的 action space 应该怎么设计？如何表达点击、输入和导航等操作？ {#q-524}

**参考答案：**

定义点击、输入、选择、滚动、导航、等待和读取等最小动作，目标带可访问名称/稳定元素引用与前置条件。动作参数有边界、超时和返回状态；提交、支付等应标注副作用并经策略判断。

## 525. sandbox 浏览器怎么搭才安全？ {#q-525}

**参考答案：**

使用独立浏览器配置和隔离容器/会话，限制下载、上传、本机文件、扩展与出站网络，防 SSRF 和访问内网元数据。按任务分配身份与资源额度，结束清理，但需保留受控审计证据。

## 526. 凭证与登录态怎么隔离？如何避免其他 Agent 或用户访问不属于自己的会话？ {#q-526}

**参考答案：**

按用户/租户独立 profile、Cookie jar 和会话存储，凭据由秘密管理或受控登录提供，模型不直接获得密码/令牌。复用会话前检查归属，截图/导出脱敏，注销和权限变化及时失效。

## 527. UI 脆弱与 flaky 问题下，浏览器 Agent 如何提高操作稳定性和失败恢复能力？ {#q-527}

**参考答案：**

优先角色/标签等稳定定位，等待明确状态而非固定 sleep，动作前重新读取目标，动作后验证结果。瞬时失败有限重试，导航后刷新引用；写操作状态不明先查询，不能重复点击提交直到成功。

## 528. 面对速率限制与反爬机制，Agent 怎么避免持续重试？如何识别限制并合理退避或请求用户介入？ {#q-528}

**参考答案：**

识别 429、Retry-After、验证码或封禁提示，停止持续请求并指数退避，降低并发或请求人工处理。尊重服务限制和合法访问边界，不用绕过验证码/身份限制作为“恢复”，避免重试放大流量。

## 529. Computer Use API 常见模式是什么？感知、动作和反馈如何形成闭环？ {#q-529}

**参考答案：**

典型闭环是获取截图/状态→选择受支持动作→执行→等待相关变化→再次观察并校验。动作具有坐标/键盘语义，需处理焦点、缩放与异步状态；高风险操作在执行前由策略验证。

## 530. Web 动作的安全 policy 应覆盖什么？如何控制提交、支付和删除等操作？ {#q-530}

**参考答案：**

策略覆盖域名/资源、账号、上传下载、外发、提交、支付、删除与权限变更，按主体和风险决定允许/确认/拒绝。确认绑定具体目标与内容，检查页面变化防 TOCTOU，日志保留动作与结果。

## 531. 浏览器 Agent 可观测性要记什么？ {#q-531}

**参考答案：**

记录 run/step、页面 URL、脱敏截图/DOM 引用、目标定位、动作参数摘要、前后状态、耗时、错误与策略决策。截图可能含敏感信息，应限制访问/保留并避免全量无差别采集。

## 532. 多 tab、多窗口编排怎么管状态？ {#q-532}

**参考答案：**

为每个 tab/window 分配稳定 ID 和所有者，维护当前 URL、导航版本、焦点、任务与上下文。动作明确指定目标，弹窗/新标签建立关联，结束关闭自有资源；不要依赖“当前标签”这种隐含全局状态。

## 533. 提取网页数据时，怎样控制幻觉并保留来源证据？ {#q-533}

**参考答案：**

抽取结果附来源 URL、标题、时间、原文片段和必要定位，优先读 DOM 文本，图片信息用视觉标注。对关键数据交叉核验，缺字段输出缺失而非猜测，并防页面内容注入指令。

## 534. Computer Use 与浏览器 Agent 有什么区别与联系？如何选择执行方式？ {#q-534}

**参考答案：**

Computer Use 可覆盖桌面/窗口/鼠标键盘，浏览器 Agent 专注网页导航与 DOM/浏览器状态。能用稳定 API/语义 DOM 时优先使用，只有必要视觉/桌面交互再用屏幕动作；两者可混合但共享权限与审计边界。

## 535. 浏览器 Agent 上线前评测怎么做？ {#q-535}

**参考答案：**

用隔离测试账号覆盖登录、导航、表单、弹窗、失败恢复、弱网和页面变化，测任务成功、误操作、重复提交、成本和延迟。加入注入/越权与敏感操作测试，沙箱通过后小流量上线并保留人工接管。
