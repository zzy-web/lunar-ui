# RAG 知识库

共 **16 题**，题号 **434–449**。 [返回分类总览](./)

> 答案用于面试复习与工程讨论，具体实现请结合项目锁定的版本验证。

## 434. RAG（检索增强生成）的原理与基本流程是什么？ {#q-434}

**参考答案：**

RAG 先从外部知识源检索相关片段，再将其作为上下文交给模型生成带依据的答案。离线建索引，在线查询、召回、重排和引用验证；检索质量与权限过滤决定可用证据，不能保证自动消除幻觉。

## 435. RAG 解决什么问题？和微调、长上下文方案有什么区别？ {#q-435}

**参考答案：**

RAG 补充可更新、可引用的外部事实；微调更适合行为、格式或领域任务适配，不适合频繁更新知识；长上下文适合相关材料可整体放入窗口时。三者可组合，按更新频率、容量、证据需求和成本选择。

## 436. 一条完整的 RAG 流水线应包含哪些步骤与组件？ {#q-436}

**参考答案：**

数据接入→解析/OCR→清洗去重→按结构切块→元数据/ACL→embedding→索引；在线鉴权→查询理解→混合召回→过滤/重排→上下文组装→生成→引用与质量验证。还需增量更新、删除同步、评测和观测。

## 437. 文档切分（Chunking）策略怎么设计？如何选择切分粒度和重叠长度？ {#q-437}

**参考答案：**

优先按标题、段落、语义和表格边界切块，控制 token 长度并保留文档层级，必要时小块召回大块返回。重叠避免信息断裂但增加重复/成本；用真实查询测召回与答案完整性，不存在统一最优字符数。

## 438. Embedding 模型怎么选？要不要根据业务数据做适配或微调？ {#q-438}

**参考答案：**

比较语言/领域覆盖、向量维度、最大输入、延迟、成本与私有部署要求。先用真实查询做检索评测，基础模型不足再考虑对比学习等适配；升级必须重建兼容索引，不能只替换查询模型。

## 439. 向量检索之外，为什么生产 RAG 还需要关键词检索或混合检索？ {#q-439}

**参考答案：**

向量擅长语义近似，关键词/BM25 擅长精确术语、型号、错误码和罕见实体。混合召回可互补，利用 RRF 或分数校准融合，再重排；权限过滤必须覆盖所有召回通道。

## 440. 重排（Rerank）层有没有必要？如何评估其效果、成本和延迟？ {#q-440}

**参考答案：**

Reranker 对查询与候选内容做更精细相关性评分，适合初召回数量较大或近似结果混杂的场景。比较 Recall/nDCG、答案成功率与增量延迟成本，控制候选数量；召回未找到正确文档时重排无法凭空补救。

## 441. Query 改写、多查询、HyDE 这些检索增强策略有什么区别，如何选择？ {#q-441}

**参考答案：**

改写澄清或标准化原问题，多查询从多个表达召回并去重，HyDE 先生成假想文档再用于检索。后两者增加调用且可能引入偏差，应保留原查询通路，按真实评测选择而非默认全部叠加。

## 442. 检索为空或分数很低时，Agent 应该如何回应或调整检索策略？ {#q-442}

**参考答案：**

先区分知识缺失、查询不清、权限过滤和索引故障，再在预算内改写/扩展或查其他权威源。仍无证据时明确不足并请求补充/转人工；相似度低不能硬凑答案，阈值需按模型和数据校准。

## 443. 知识库更新、增量索引和版本管理怎么做？ {#q-443}

**参考答案：**

为文档和块保存稳定 ID、内容 hash、来源/ACL 与索引版本，按变更增量更新并传播删除。索引任务可重试去重，记录同步水位和错误；发布时验证覆盖率，保留历史版本供引用与回滚。

## 444. 多租户知识库怎么做隔离？ACL 权限如何贯穿检索与生成流程？ {#q-444}

**参考答案：**

身份贯穿查询、混合召回、重排、缓存、上下文与引用，每条证据检查 tenant 和资源 ACL。源权限变更/删除要同步并在生成前复核，缓存键包含授权范围，不能仅让模型决定用户是否有权看内容。

## 445. RAG 效果怎么评测？除了人工看答案，还应该评估哪些检索与生成指标？ {#q-445}

**参考答案：**

检索测 Recall@k、MRR/nDCG、空检索与 ACL 违规；生成测事实忠实度、答案完整性、引用准确性和任务成功率。结合人工与自动评测，加入无答案、过时知识和恶意文档，同时统计延迟与成本。

## 446. Agentic RAG 和传统单次检索有什么区别？适用于哪些场景？ {#q-446}

**参考答案：**

传统 RAG 一次检索再生成，Agentic RAG 可拆问题、选择数据源、多轮检索并根据证据继续。适合复杂、多跳任务，但成本/循环风险更高；设置检索预算和可验证终止条件。

## 447. 结构化数据（表格、数据库）和非结构化文档如何共同接入 RAG？ {#q-447}

**参考答案：**

文档用解析切块索引，结构化数据通过受控 SQL/语义层工具查询，统一附来源与版本。表格需保留行列/单位，精确汇总用数据库/计算工具而非只嵌入表格文本；跨源联结要校验实体与权限。

## 448. 知识库安全：如何防范投毒、越权和敏感信息泄露？ {#q-448}

**参考答案：**

接入源需可信与可追踪，文档做恶意内容检测和版本审查，检索执行 ACL，输出审查敏感信息。外部文本不能修改工具策略，缓存与日志按租户隔离；攻击测试覆盖投毒、注入与越权召回。

## 449. 从 Demo RAG 到生产知识库，最需要优先解决哪些工程问题？ {#q-449}

**参考答案：**

优先解决数据解析质量、更新/删除/权限同步、检索评测、证据引用和空结果处理。再补观测、容量、成本与灾备；不能把“接了向量库”当作生产知识库已经完成。
