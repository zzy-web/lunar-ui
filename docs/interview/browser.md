## 146. 【推导】浏览器的渲染过程是什么？DOM 树和 CSSOM 树如何构建并参与页面渲染？ {#q-146}

**参考答案：**

HTML 解析生成 DOM，CSS 解析生成 CSSOM，结合可见节点构建渲染信息，计算样式和布局，再绘制、分层与合成。JS、样式与字体加载可能影响阶段执行；现代浏览器按增量方式更新，不是只执行一次的直线流程。

## 147. 【推导】浏览器输入 URL 到页面加载显示，经历了哪些过程？ {#q-147}

**参考答案：**

先解析 URL、检查策略/缓存，必要时 DNS、建立 TCP 或 QUIC 与 TLS 连接，发送请求并处理重定向。收到 HTML 后解析、加载资源、执行脚本并渲染；Service Worker、缓存、连接复用会使实际路径变化。

## 148. 性能优化相关的参考指标有哪些？ {#q-148}

**参考答案：**

体验指标关注 LCP、INP、CLS，辅以 TTFB、FCP、资源体积、长任务、内存与业务转化。区分实验室测量与真实用户数据，按设备、网络和分位数分析；单次本地跑分不能代表线上用户。

## 149. performance 对象。 {#q-149}

**参考答案：**

performance 提供高精度时间、mark/measure 和资源/导航等 PerformanceEntry，PerformanceObserver 可持续订阅。用 performance.now 计时避免系统时钟调整影响；指标采集需控制开销、隐私与浏览器支持差异。

## 150. 【推导】localStorage、sessionStorage 有什么区别？分别适用于哪些场景？ {#q-150}

**参考答案：**

二者都是按源隔离的同步字符串存储；localStorage 通常跨会话保留，sessionStorage 按页面会话/顶层标签隔离并在会话结束后清理。适合少量偏好或临时状态，不适合大量数据或明文凭据；配额和隐私模式行为可能不同。
