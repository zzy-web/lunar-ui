# 记忆系统

共 **15 题**，题号 **450–464**。 [返回分类总览](./)

> 答案用于面试复习与工程讨论，具体实现请结合项目锁定的版本验证。

## 450. Agent 记忆和 RAG、聊天历史有什么区别与联系？ {#q-450}

**参考答案：**

聊天历史是原始交互，RAG 是检索外部知识的方法，记忆是筛选后可跨任务复用的事实/偏好/经历。记忆可借向量检索实现，但需要来源、有效期、纠错和授权，不能自动把历史都当真。

## 451. 短期记忆、长期记忆、情景记忆分别是什么？如何划分和使用？ {#q-451}

**参考答案：**

短期记忆维持当前 run/会话，长期记忆保存跨任务有价值信息，情景记忆保存具体事件及时间背景。可同时使用结构化画像和事件检索，按相关性与新鲜度装入上下文，不是简单越存越多。

## 452. 用户画像（User Profile）应有哪些字段？如何更新和使用？ {#q-452}

**参考答案：**

画像可含用户明确偏好、语言、时区、角色、允许使用的业务属性，以及来源、更新时间和置信/确认状态。仅收集必要信息，当前明确指令优先，提供用户查看、修改与删除能力。

## 453. 记忆什么时候写入？任务中写还是任务结束后写，各有什么取舍？ {#q-453}

**参考答案：**

任务中写便于即刻复用，但事实可能尚未确认；结束后写更完整，但中断时可能丢失。可先暂存候选、关键确认事实及时持久化，任务结束归并；避免把模型假设或失败计划写成事实。

## 454. 记忆提取怎么做？直接用 LLM 总结是否足够，如何保证准确性和可追溯性？ {#q-454}

**参考答案：**

LLM 可提出候选记忆，但需引用原始事件、区分用户声明/推断、校验主体和冲突后再写。使用 schema、去重、有效期与敏感信息规则，必要时用户确认；单次无来源摘要不足以作为权威记忆。

## 455. 记忆检索挂在 Agent 的哪一环？每轮都检索还是按需触发？ {#q-455}

**参考答案：**

Context Builder 在调用模型前按任务需要检索，事件完成后可更新候选记忆。稳定画像可轻量常驻，情景/大段记忆按需召回，控制数量与新鲜度；每轮无差别检索会增加噪声与成本。

## 456. 向量记忆和结构化画像库能否只选一种？如何分工与协作？ {#q-456}

**参考答案：**

结构化画像适合语言、时区、明确偏好等精确字段，向量记忆适合自然语言经历和语义召回。二者通过稳定 ID/来源关联，通常互补；小系统可先选简单方案，但必须保留纠错和权限能力。

## 457. 用户当前说的内容和记忆里存的内容冲突时怎么办？如何判定和更新？ {#q-457}

**参考答案：**

先区分新事实覆盖旧事实、临时指令或主体混淆，当前用户明确表达通常优先用于本次任务。长期更新保存来源与生效时间，冲突不明确时澄清，不静默删除历史或用旧记忆否定用户当前要求。

## 458. 记忆系统的隐私、合规与用户删除请求如何处理？ {#q-458}

**参考答案：**

实行数据最小化、明确用途和作用域，敏感信息限制写入并加密访问。删除需覆盖画像、向量、缓存与派生索引，备份按保留策略失效并防恢复后复活；具体法律义务应由适用地区专业审查确定。

## 459. 记忆过期、纠错与陈旧事实怎么治理？ {#q-459}

**参考答案：**

记忆带来源、更新时间、有效期与版本，周期性合并重复、撤销错误并标记过期。高变化事实在执行前重新核实，用户纠错应更新所有关联视图，保留必要审计但不继续向模型召回失效内容。

## 460. 多 Agent 或多会话并行时，记忆怎么共享、隔离并处理并发更新？ {#q-460}

**参考答案：**

默认私有到用户/租户，按任务显式共享必要记忆；更新使用版本号、事务或事件归并避免最后写覆盖。保留主体/时间/来源，不能把不同用户或并行任务的推断合成一个无差别事实。

## 461. 记忆和 RAG、Skill 有什么区别与联系？如何划分职责？ {#q-461}

**参考答案：**

RAG 回答“资料里有什么”，Memory 回答“过去确认了什么”，Skill 回答“这类任务怎么做”。可由 Skill 指导调用 RAG 和 Memory，但来源、权限和更新周期各自管理，不应把用户隐私固化到公共 Skill。

## 462. 怎么评测记忆系统好不好？ {#q-462}

**参考答案：**

测写入正确率、召回相关性、过期事实使用率、冲突解决、删除完成率及越权泄露。用有/无记忆对照任务评估实际收益、成本与误导率；记住更多内容不等于更好。

## 463. 从 Demo（只有 messages 数组）演进到生产记忆系统，需要补齐哪些能力？ {#q-463}

**参考答案：**

增加结构化 schema、来源关联、候选审核、检索、去重、过期/纠错、用户隔离和删除。把对话历史与长期事实分库/分模型管理，并建立回归数据和访问审计，避免无界 messages 数组。

## 464. 程序化记忆、语义记忆、情景记忆有什么区别？分别适用于哪些场景？ {#q-464}

**参考答案：**

程序化记忆保存操作方法/流程，语义记忆保存事实与概念，情景记忆保存某次经历及时间来源。程序化可由受控 Skill 提供，语义适合画像/知识，情景适合历史案例；都要管理适用性与时效。
